SCTE Plugin Generator

Generate a hardened SCTE-35 plugin scaffold for the Uplynk LiveSlicer. Fill in the metadata, pick one or more channel-group methods, toggle the optional features, and download a zip.

{# ===================================================================== Section 2 — Methods (multi-select checkboxes) ===================================================================== #}
Methods to include

Check any 1–3. Each generates a channel-group method dispatched from Process35 on the channel_group config value. SCTELogger is always included as a diagnostic fallback (channel_group: scte_logger).

{# --- Linear method --- #}

Standard linear channel with Type 5 (splice_insert) OR Type 6 (34/35, 48/49, 54/55) ad breaks, selected at runtime via scte_ad_break_mode. Type 16 program starts handled independently.

Leave blank to auto-derive PascalCase from channel_group. Override for acronym cases (e.g. CBSSportsUnified).
{# --- Live Event method --- #}

Disney-style lifecycle handler for Types 16/17/19/20/54/55 using the Uplynk Live Events API. Async event start/end/update via slicer.APICall, terminal-state guards, slicer_id mismatch detection, sentinel contracts.

{# --- OON method --- #}

P1Media-style out-of-network handler with async slicer.WebCall for EPG title enrichment before firing AdStart/StartBoundary. State-machine tracking, stale-ad recovery, blackout init.

{# ===================================================================== Section 3 — Optional features ===================================================================== #}
Optional features

Feature flags apply plugin-wide — they emit shared helpers and globals available to every included method.
